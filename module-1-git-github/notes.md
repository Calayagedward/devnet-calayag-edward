## Key vocabulary (in your own words)

- repository: is a storage area (weather it's through git/offline or github/online), where you can create a projects or anything inside of it.

- commit: staging area (already saved but not been uploaded yet on the repo) where the machine is waiting for your command for the file/poject to be push or upload to the repository.

- branch: is like a folder or a workspace where your projects been saved. You acn also create a seperate branch.

- push / pull: push, is you are going to upload your file to the repository (weather it's a updated file or a new file). However, pull is vise versa; where the file from a specific repository will be pulled or like; it will be copied.

- pull request: is a request where someone updates or create a modifications/changes on the file/project inside the same repo and the main collaborator will have the access to pulled that request.

- merge conflict: sometimes happen when the two users or collaborators update a same project/file with the same changes. And git doesn't know or it gets a little confused to those two branches whose the main/master branch is.
